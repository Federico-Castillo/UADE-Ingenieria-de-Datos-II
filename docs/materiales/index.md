# Materiales

Material provisto directamente por los docentes de la cátedra.

- [Clases](clases.md) — grabaciones, notas o archivos compartidos en cada clase
- [Presentaciones](presentaciones.md) — slides / diapositivas de la cátedra

!!! info "Sobre archivos adjuntos"
    Para archivos livianos (PDF, slides), se pueden subir a `docs/materiales/archivos/`
    y linkearlos desde la página correspondiente. Para archivos pesados, es
    preferible linkear a Drive/campus virtual en vez de versionarlos en el repo.
