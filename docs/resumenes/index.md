# Resúmenes

Resúmenes de teoría organizados por unidad, pensados para repaso rápido antes
de un parcial o final.

!!! info "Convención"
    Un archivo por unidad: `resumenes/unidad-N.md`. Agregar la entrada
    correspondiente en la sección `nav > Resúmenes` de `mkdocs.yml`.
