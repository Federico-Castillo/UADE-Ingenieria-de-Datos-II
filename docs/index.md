# Ingeniería de Datos II — UADE

Apunte y wiki personal de la materia **Ingeniería de Datos II** (Universidad
Argentina de la Empresa). Este sitio se construye de forma progresiva durante
la cursada: cada clase, guía o ejercicio resuelto se agrega como una página
Markdown nueva.

!!! info "Estado del sitio"
    Esta es la base inicial del proyecto. Las secciones existen y navegan
    correctamente, pero el contenido específico de la materia (programa,
    unidades, ejercicios, etc.) todavía no fue cargado. Ver
    [Información de la materia](info-materia/index.md) y las páginas de
    ejemplo de cada sección.

## Cómo usar este sitio

- Usá el **buscador** (arriba) para encontrar contenido por palabra clave.
- La navegación superior agrupa el contenido por sección; dentro de cada
  sección, el menú lateral lista las páginas disponibles.
- El ícono de lápiz (arriba a la derecha de cada página) abre el archivo
  Markdown correspondiente en GitHub para editarlo rápido.
- Ver [Cómo agregar contenido](recursos/como-agregar-contenido.md) para el
  flujo de trabajo al sumar una página nueva.

## Objetivo

Centralizar en un solo lugar, con buena navegación y buscador, todo el
material de estudio de la materia para facilitar el repaso y la preparación
de exámenes.
